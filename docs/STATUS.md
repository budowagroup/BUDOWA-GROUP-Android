- Реалізовано перегляд **9 вкладок** (5 годин/зарплат і 4 фінансів/закупівель), сортування, картки, кольори, фінансову панель.
- Останні попередньо підтверджені GitHub збірки Android і backend tests проходили. Нові коміти перевіряються окремо; не переносити старий зелений статус на новий код.
- У тестовому репозиторії є `lib/sheet_record_editor.dart` та `backend/Code.gs` v0.5 із підготовленими CREATE/UPDATE і захистом формул; це **не означає, що запис увімкнено на сервері**.

## Оновлення 23.11.2026 — підготовка APK до безпечного переходу v0.5

- **Код:** Flutter тепер показує версію підключеного API та підтверджену сервером назву джерела даних. Неповні права `write/create/update`, невідома роль або стара відповідь v0.4 не вмикають TEST-запис.
- **Сервер:** `backend/Code.gs` v0.5 повідомляє `dataSource: BG TEST Android API`; оновлено backend-тест відповіді health.
- **Тести APK:** додано `test/api_health_status_test.dart`; GitHub Actions тепер запускає всі Flutter-тести. **Android debug APK 0.2.1+3 — [CI 23.11.2026](https://github.com/budowagroup/BUDOWA-GROUP-Android/actions/runs/45184775918) успішний:** аналіз, повний Flutter test, налаштування підпису, компіляція та перевірка APK пройшли. Це не підтвердження живого запису в Google Sheets.
- **Джерела:** у Google Drive існують інші копії з назвою «TEST актуальна 20.11.2026». Поточний API в репозиторії налаштовано на пару «BG TEST Android API» від 17.11.2026. **Не перемикати** ID або не зливати дані без окремої звірки та плану.
- **Залишається блокером #3:** незалежна перевірка backup v0.4, приватних дозволів/Script Properties і безпечне живе розгортання. Зміна GitHub **не розгортає** Apps Script автоматично.
- **Залишається блокером #4:** фактичний запис у Google Sheets не перевірений; `ENABLE_TEST_WRITES` не вмикати до успішних Gate A/B. Оригінали і резервні копії в цьому етапі не змінювалися.

## Оновлення — перевірка TEST-з'єднання у версії 0.2.2+4

- В Android додано окремий екран перевірки **9 вкладок**, який читає один рядок із кожної TEST-вкладки через наявний авторизований API.
- Кожен результат показує успіх, порожній рядок або безпечний код помилки; невдала вкладка не перериває решту перевірок.
- Перевірка працює виключно через `action=read`, з лімітом `limit=1`; у неї немає операцій створення, редагування або видалення.
- Додано unit-тести для дев'яти назв/діапазонів, read-only запитів, відмови доступу й некоректних відповідей. **Android CI [#45186871179](https://github.com/budowagroup/BUDOWA-GROUP-Android/actions/runs/45186871179) — success:** Flutter analyze, всі unit-тести, debug-підписання, перевірка SHA-256/архіву й завантаження APK 0.2.2+4 виконані.
- Зміни в GitHub **не оновлюють Apps Script deployment автоматично**. P0 #3 і #4 залишаються відкритими до перевірки на реальному планшеті та в TEST Google Sheets.

## Розробка 23.11.2026 — TEST-форми запису/редагування (APK 0.3.0+5)

- Для записів годин, історії ставок і фінансових операцій поля працівника, об'єкта, закупівельника та категорії тепер беруться **безпосередньо з TEST-довідників** через `action=read`. При помилці/неповноті обов'язкових довідників запис не відкривається.
- Перед відкриттям форми та безпосередньо перед кожним `create/update` Android повторно перевіряє роль, версію API, джерело `BG TEST Android API` і явні `write/create/update` capabilities.
- Заборонені перейменування залежних ключів заблоковані в UI, щоб не пошкодити формули. Редагування розрахункових полів не дозволене.
- Після позитивного запису користувач отримує окреме повідомлення про успіх або про неуспішне оновлення списку. Реальний TEST E2E запис після розгортання сервера **все ще потрібний**.
- Поточний підтверджений на планшеті API v0.4 залишається лише для читання. **Розгортання серверного v0.5, налаштування дозволів і TEST-запис у Sheets не виконувалися цим комітом.**
- Оригінальні облікові таблиці й backup-автоматизації не змінюються.

## Додаткове виправлення 23.11.2026 — повнота завантаження 0.3.1+6

- Android не перериває читання при порожніх блоках по 100 рядків. Фізичні номери рядків зберігаються для точного UPDATE.
- Підготовлений TEST Apps Script v0.5 підтримує opt-in `includeMeta`: повідомляє останній змістовний рядок. Для фінансових довідників перевіряються **обидві** колонки.
- Старий v0.4 продовжить працювати без метаданих (більше запитів). Код backend не розгорнутий автоматично.
- Додано регресійні тести для пропусків між записами. Оригінальні та резервні таблиці залишаються недоторканими.

## Незмінні правила

- Оригінальні Google Sheets і backup-автоматизації **не змінюються**.
- Debug APK — не реліз; mock tests — не доказ успішного живого запису.
- Власник єдиний, хто може бачити історію дій та змінювати TEST-записи. Адміни, доки не узгоджено інакше, — тільки читання.
- Всі зміни підтверджуються комітами, CI і за потреби живими тестами; без верифікації — статус «у роботі».
